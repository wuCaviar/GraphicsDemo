# 矢量图形栅格化 CMYK TIFF 输出系统 — 项目初期文档

---

## 一、项目概述

### 1.1 项目目标

构建一套将矢量图形描述数据渲染为 CMYK 色彩空间 TIFF 图像文件的完整管线，满足印刷及专业出版领域的色彩管理与输出质量要求。

### 1.2 核心能力

- 解析结构化的矢量图元描述数据（几何属性、外观属性、嵌入图片）
- 参照 SVG 渲染模型完成矢量光栅化（路径解析、曲线扁平化、扫描线填充、抗锯齿、合成）
- 支持嵌入多格式位图（JPEG、PNG、WebP、BMP、GIF、TIFF、PSD、AVIF 等），统一解码与变换
- 统一色彩管理，将混合内容转换至 CMYK 色域
- 以 TIFF 格式无损输出，嵌入 ICC Profile，满足印刷交付标准

### 1.3 目标场景

| 场景         | 说明                                                |
| ------------ | --------------------------------------------------- |
| 印前输出     | 杂志、画册、包装等印前文件的矢量→印刷就绪 TIFF 转换 |
| 专业出版     | 出版物中混合矢量排版与嵌入位图的页面栅格化          |
| 自动化流水线 | 可集成至 CI/CD 或批处理系统，实现大规模文件自动转换 |
| 设计工具后端 | 为设计软件提供底层渲染与导出能力                    |

### 2.2 分层职责

| 层次         | 职责                 | 输入                        | 输出                   |
| ------------ | -------------------- | --------------------------- | ---------------------- |

| 输出层       | 文件写入             | CMYK 像素阵列               | TIFF 文件              |

## 三、关键技术方案

### 3.1 矢量图元描述与路径系统

#### 图元模型

参照 SVG 规范，支持以下基本图元：

| 图元             | 描述                     |
| ---------------- | ------------------------ |
| 矩形 (rect)      | 位置、宽高、可选圆角半径 |
| 圆形 (circle)    | 圆心、半径               |
| 椭圆 (ellipse)   | 中心、x/y 半径           |
| 线段 (line)      | 起止坐标                 |
| 多边形 (polygon) | 闭合顶点序列             |
| 折线 (polyline)  | 开放顶点序列             |
| 路径 (path)      | 完整 SVG 路径命令集      |

#### 路径命令集

完整支持 SVG path `d` 属性的全部命令：

- **移动与直线**：M (moveto)、L (lineto)、H (horizontal lineto)、V (vertical lineto)、Z (closepath)
- **曲线**：C (三次贝塞尔)、S (光滑三次)、Q (二次贝塞尔)、T (光滑二次)
- **弧线**：A (椭圆弧，含 large-arc-flag / sweep-flag)
- **大小写语义**：大写=绝对坐标，小写=相对坐标
- **隐式连续**：M 后的隐式 L，C 后的隐式 S 等

#### 曲线扁平化

所有曲线需在光栅化前转换为折线序列：

- **三次贝塞尔**：de Casteljau 递归细分，平坦度检测阈值 ≤ 0.25 像素，最大递归深度 16
- **二次贝塞尔**：同样递归细分
- **椭圆弧**：参照 SVG 规范的端点→中心参数化转换，每段弧用三次贝塞尔逼近，最大跨距 π/2

### 3.2 仿射变换体系

支持完整的二维仿射变换，对应 SVG `transform` 属性：

| 变换类型      | 参数             | 矩阵                   |
| ------------- | ---------------- | ---------------------- |
| translate     | tx, ty           | 平移                   |
| scale         | sx, sy           | 缩放                   |
| rotate        | angle [, cx, cy] | 旋转（可指定旋转中心） |
| skewX / skewY | angle            | 错切                   |
| matrix        | a, b, c, d, e, f | 任意仿射变换           |

变换按嵌套顺序级联组合（子节点继承父节点变换），在光栅化阶段通过逆变换将画布像素映射回图元局部坐标空间进行采样。

### 3.3 填充与描边

#### 填充

- **填充规则**：支持 nonzero（非零绕数）和 evenodd（奇偶）两种规则
- **填充内容**：纯色、线性渐变、径向渐变、图案平铺
- **渐变参数**：
  - 线性渐变：渐变向量、stop 序列（offset + color + opacity）、spreadMethod (pad/reflect/repeat)
  - 径向渐变：焦点圆与主圆参数、stop 序列、spreadMethod
  - objectBoundingBox 与 userSpaceOnUse 两种坐标模式
- **填充透明度**：独立的 fillOpacity 属性

#### 描边

- **宽度**：strokeWidth（像素单位）
- **线帽 (linecap)**：butt / round / square
- **连接方式 (linejoin)**：miter / round / bevel
- **尖角限制 (miterLimit)**：防止尖角过长
- **虚线模式 (dasharray + dashoffset)**：支持任意虚线序列
- **描边展开**：将路径偏移 width/2 距离，生成闭合轮廓后走填充流程

### 3.4 抗锯齿策略

采用**覆盖率扫描线栅格化**：

- 像素中心偏移 0.5px 采样
- 边缘区域在 [-0.5, +0.5] 像素范围内做线性覆盖率过渡
- 输出每像素 0-255 的覆盖率值到 CoverageBuffer
- 着色时将 alpha 乘以覆盖率，实现亚像素精度抗锯齿

### 3.5 合成模型

严格参照 SVG 渲染模型的画家算法（Painter's Algorithm）：

**合成流程**：

1. 按文档树深度优先顺序遍历
2. 每个节点渲染到当前帧缓冲
3. 帧缓冲使用浮点 RGBA 中间表示，避免多层合成的精度累积损失

**Alpha 合成**：

- 采用 Porter-Duff "over" 算子
- 公式：outA = srcA + dstA × (1 − srcA)

**混合模式**：

- 支持 normal、multiply、screen、overlay、darken、lighten
- 后续可扩展为 CSS/SVG 完整混合模式集

**Opacity 组隔离**：

- 当组 opacity < 1 时，先将子内容渲染到独立透明缓冲区
- 整体乘以 opacity 后再合成到父缓冲
- 避免组内元素互相透明穿透

### 3.6 嵌入位图处理

#### 多格式解码

| 格式      | 说明             | 关键特性                                            |
| --------- | ---------------- | --------------------------------------------------- |
| JPEG      | 最常见的照片格式 | 支持 ICC 提取、CMYK JPEG 反相处理、EXIF Orientation |
| PNG       | 无损、支持 Alpha | 支持 iCCP/sRGB chunk、透明通道                      |
| WebP      | 现代压缩格式     | 支持 ICC、Alpha、动画（取首帧）                     |
| BMP       | Windows 位图     | BGRA/BGR/8位灰度/调色板                             |
| GIF       | 可能为动画       | 取首帧，支持透明色                                  |
| TIFF      | 嵌套 TIFF        | 可能已是 CMYK、支持多页                             |
| PSD       | Photoshop 文件   | 图层合并可见层                                      |
| AVIF/HEIF | 新一代压缩       | 手机拍摄常见                                        |

**解码策略**：

- 通过文件头魔数（magic bytes）自动检测格式
- 统一解码为 RGBA 4通道 8bit 像素缓冲
- 提取并保留原始 ICC Profile
- EXIF Orientation 自动校正（支持全部 8 种方向）

#### 色彩空间适配

不同图片源可能携带不同的色彩空间标记或 ICC Profile：

- **sRGB（大多数情况）**：直接使用
- **Adobe RGB**：通过色度参数构造 Profile 后转换
- **ProPhoto RGB**：同上
- **CMYK（扫描件等）**：先转 sRGB 再参与合成，或保留原始数据在最终阶段直接转目标 CMYK
- **灰度**：扩展为 RGB 后参与统一合成
- **无 ICC 标记**：回退假设为 sRGB

#### 图片放置与变换

参照 SVG `<image>` 的放置语义：

- **位置与尺寸**：x, y, width, height 定义目标矩形
- **宽高比保持 (preserveAspectRatio)**：
  - meet 模式：完整显示，可能留白
  - slice 模式：填满区域，可能裁切
  - 对齐锚点：xMin/xMid/xMax × yMin/yMid/yMax
- **仿射变换**：缩放、旋转、错切等组合应用
- **裁切路径 (clipPath)**：图片可被任意路径裁切

#### 重采样算法

| 算法              | 适用场景           | 特点                            |
| ----------------- | ------------------ | ------------------------------- |
| 最近邻 (Nearest)  | 像素艺术、极速预览 | 无插值、锯齿明显                |
| 双线性 (Bilinear) | 一般用途           | 质量/速度平衡                   |
| 双三次 (Bicubic)  | 高质量缩小         | Mitchell-Netravali 核，平滑锐利 |
| Lanczos (3-lobe)  | 印刷级质量         | 锐度最高，可能产生振铃          |

印刷输出建议默认使用 Bicubic 缩小、Lanczos 放大。

### 3.7 色彩管理

#### 色彩管理策略

采用**两段式转换**，确保色域映射的正确性：

```
各源色彩空间 ──→ sRGB (统一合成空间) ──→ 目标 CMYK (输出空间)
```

- **第一段**：解码阶段，各嵌入图片的原始色彩空间 → sRGB（使用 LittleCMS）
- **第二段**：输出阶段，合成完成的 sRGB 帧缓冲 → 目标 CMYK

**为什么不在 CMYK 空间合成**：

- 矢量图元描述（渐变、纯色等）通常以 RGB 值给出
- Porter-Duff 合成的数学模型基于线性 RGB 空间
- CMYK 空间合成会引入不必要的精度损失

#### ICC Profile 体系

| Profile           | 用途                           |
| ----------------- | ------------------------------ |
| sRGB Profile      | 合成工作空间（LittleCMS 内置） |
| 目标 CMYK Profile | 输出设备特性化文件             |
| 源图片 ICC        | 从嵌入图片中提取               |

**目标 CMYK Profile 选择建议**：

| Profile 名称         | 适用场景                    |
| -------------------- | --------------------------- |
| USWebCoatedSWOPv2    | 北美商业印刷（铜版纸涂布）  |
| Fogra39              | 欧洲胶印标准（ISO 12647-2） |
| Fogra51              | 欧洲新一代标准              |
| JapanColor2001Coated | 日本印刷标准                |
| GRACoL2006           | 北美高端商业印刷            |

**渲染意图**：

| 意图                             | 适用场景                             |
| -------------------------------- | ------------------------------------ |
| 感知 (Perceptual)                | 照片类内容，整体压缩色域保持视觉关系 |
| 相对比色 (Relative Colorimetric) | 品牌色、Logo，保持色域内颜色精确     |
| 绝对比色 (Absolute Colorimetric) | 专色校样                             |
| 饱和 (Saturation)                | 商业图表、信息图                     |

建议默认使用感知意图 + 黑点补偿（Black Point Compensation）。

#### 总墨量控制 (TAC)

印刷介质对承印墨量有物理限制：

- **铜版纸涂布**：≤ 320-340%
- **胶版纸非涂布**：≤ 280-300%
- **新闻纸**：≤ 240-260%

系统在 CMYK 转换完成后，逐像素检测 C+M+Y+K 总值，对超限像素做等比例缩放。

## 四、输入数据规范

### 4.1 画布配置

| 字段       | 类型   | 说明                       |
| ---------- | ------ | -------------------------- |
| width      | 整数   | 画布宽度（像素）           |
| height     | 整数   | 画布高度（像素）           |
| dpi        | 整数   | 输出分辨率（印刷建议 300） |
| background | 色彩值 | 画布背景色                 |

**常用画布尺寸参考（300 DPI）**：

| 纸张             | 像素尺寸    |
| ---------------- | ----------- |
| A4 (210×297mm)   | 2480 × 3508 |
| A3 (297×420mm)   | 3508 × 4961 |
| Letter (8.5×11") | 2550 × 3300 |

### 4.2 图元数据结构

每个图元应包含以下属性组：

**几何属性**：

- 类型标识（rectangle / ellipse / line / polygon / polyline / path）
- 位置坐标 (x, y)
- 尺寸 (width, height) 或顶点序列
- 圆角半径（矩形）
- 旋转角度
- SVG 路径数据 (d 属性)

**外观属性**：

- 填充色 (RGBA)
- 填充规则 (nonzero / evenodd)
- 描边色 (RGBA)
- 描边宽度、线帽、连接方式、虚线模式
- 渐变定义（ID、类型、stops、坐标模式）
- 图案定义

**控制属性**：

- 不透明度 (0-1)
- 变换矩阵
- 裁切路径引用
- 混合模式

### 4.3 嵌入图片数据

| 字段       | 说明                                             |
| ---------- | ------------------------------------------------ |
| 图片源     | 文件路径 / Base64 内嵌 / URL                     |
| 目标位置   | x, y, width, height                              |
| 宽高比策略 | preserveAspectRatio (meet/slice/none + 对齐锚点) |
| 变换       | transform 矩阵                                   |
| 不透明度   | opacity                                          |
| 混合模式   | blend-mode                                       |
| 裁切       | clipPath 引用                                    |

## 五、输出文件规范

| ------------ | ------------------------------ |

- 源文件名
- 输出分辨率

- 生成时间戳

## 七、性能设计

### 7.1 内存策略

| 策略              | 说明                                                            |
| ----------------- | --------------------------------------------------------------- |
| 帧缓冲精度        | 合成阶段使用 float32 RGBA，避免 8bit 多层合成精度损失           |
| 大图分块 (Tiling) | 超大画布（如 A0 1200DPI ≈ 4.7GB）按 Tile 分块处理，控制内存峰值 |
| 嵌入图片解码      | 按需解码（懒加载），不在启动时一次性加载全部图片                |
| 渐变缓存          | 对 1D 渐变预计算查找表，避免逐像素重复计算                      |

### 7.2 计算优化

| 环节       | 优化方向                                               |
| ---------- | ------------------------------------------------------ |
| 路径扁平化 | 预计算扁平化结果，多个采样点复用                       |
| 扫描线填充 | 活动边表 (AET) 排序使用插入排序（局部有序）            |
| 逆变换采样 | 只在包围盒范围内迭代，跳过大量空白像素                 |
| 重采样     | SIMD 加速双线性/双三次插值                             |
| ICC 转换   | LittleCMS 批量转换（一次处理整行或整块），利用内部缓存 |
| TAC 钳制   | SIMD 向量化逐像素总墨量检测与缩放                      |

### 7.3 并行化

| 方案        | 适用环节                                  |
| ----------- | ----------------------------------------- |
| 多线程分块  | 将画布划分为独立 Tile，各线程并行渲染     |
| 流水线并行  | 解码、变换、合成各阶段流水线衔接          |
| SIMD 向量化 | 像素级逐通道运算（ICC 转换、TAC、重采样） |

## 八、质量保障

### 8.1 色彩准确性

| 检验项         | 方法                                               |
| -------------- | -------------------------------------------------- |
| ICC 转换正确性 | 标准色卡测试图（IT8.7/3）转换后与参考值比对 ΔE     |
| 色域映射       | 包含超色域饱和色的测试图，验证感知意图的平滑映射   |
| 总墨量         | 检测输出 TIFF 任意像素 C+M+Y+K 不超限              |
| CMYK JPEG      | 含内嵌 ICC 的 CMYK JPEG 嵌入后，输出色彩应与源一致 |

### 8.2 几何精度

| 检验项     | 方法                                             |
| ---------- | ------------------------------------------------ |
| 路径精度   | 对比扁平化结果与参考渲染器（如 Cairo）的像素差异 |
| 渐变平滑度 | 检查渐变带状伪影（banding），验证足够的采样精度  |
| 抗锯齿质量 | 斜线/曲线边缘的覆盖率过渡是否平滑                |
| 变换精度   | 旋转/缩放后图元位置与参考点的偏差                |

### 8.3 文件合规性

| 检验项    | 方法                                                |
| --------- | --------------------------------------------------- |
| TIFF 结构 | 使用 `tiffinfo` / `exiftool` 验证标签完整性         |
| ICC 嵌入  | 验证输出 TIFF 中 ICC Profile 可被第三方软件正确读取 |
| 印前验证  | 用 Acrobat Preflight 或类似工具检查印刷就绪性       |
| 交叉验证  | 与 ImageMagick `convert` 输出进行视觉对比           |

### 8.4 测试矩阵

| 维度         | 覆盖范围                                               |
| ------------ | ------------------------------------------------------ |
| 图元类型     | 全部 7 种基本图形 + 复杂路径 + 嵌套组                  |
| 路径命令     | 全部 SVG path 命令（含大小写、隐式连续）               |
| 嵌入图片格式 | JPEG / PNG / WebP / BMP / GIF / TIFF / PSD / AVIF      |
| 图片色彩空间 | sRGB / Adobe RGB / CMYK JPEG / 灰度 / 无 ICC           |
| 变换组合     | 平移 + 缩放 + 旋转 + 错切 + 嵌套级联                   |
| 特殊情况     | 退化路径（零面积）、极端尺寸、1×1 像素图元、全透明图层 |

## 十、风险与应对

| 风险                         | 影响                 | 应对策略                                                       |
| ---------------------------- | -------------------- | -------------------------------------------------------------- |
| CMYK JPEG 反相处理遗漏       | 输出色彩完全错误     | 解码阶段检测 colorspace=CMYK，强制反相 + ICC 转换              |
| 嵌入图片缺失 ICC Profile     | 色彩偏差             | 回退假设 sRGB，日志告警，提供配置覆盖选项                      |
| 总墨量超限导致印刷事故       | 印品干燥不良、蹭脏   | 输出前强制 TAC 钳制，可配置阈值                                |
| 超大画布内存不足             | 崩溃                 | 分块 (Tile) 渲染架构，按需加载图片                             |
| 路径退化（零面积、NaN 坐标） | 渲染异常             | 输入数据校验，退化路径安全跳过                                 |
| 字体/文字缺失                | 矢量图中文字无法渲染 | 初期将文字预转为路径（text-to-path），后期可扩展文本光栅化模块 |
| 色彩管理库版本差异           | 不同环境下输出不一致 | 锁定 lcms2 版本，内置 sRGB Profile 不依赖系统文件              |

## 十一、术语表

| 术语        | 说明                                                                                         |
| ----------- | -------------------------------------------------------------------------------------------- |
| CMYK        | 青(Cyan)、品红(Magenta)、黄(Yellow)、黑(Key/Black)，减色模型                                 |
| ICC Profile | 国际色彩联盟定义的设备色彩特性描述文件                                                       |
| TAC         | Total Area Coverage，总墨量/总面积覆盖率                                                     |
| PCS         | Profile Connection Space，设备无关的中间色彩空间 (Lab/XYZ)                                   |
| 渲染意图    | ICC 转换时的色域映射策略 (Perceptual/Relative Colorimetric/Absolute Colorimetric/Saturation) |
| SDF         | Signed Distance Field，有符号距离场，用于高效几何包含测试                                    |
| Porter-Duff | 标准 Alpha 合成算子体系                                                                      |
| 扁平化      | 将曲线转换为折线序列的过程                                                                   |
| 扫描线      | 逐行像素处理的栅格化方法                                                                     |
| 覆盖率      | 像素被图元覆盖的比例 (0-1)，用于抗锯齿                                                       |
| 活动边表    | 扫描线算法中与当前扫描线相交的边集合                                                         |
